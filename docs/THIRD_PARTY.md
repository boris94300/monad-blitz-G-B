# Bibliothèques et modèle

Code de l’application original, écrit pour le hackathon. Les bibliothèques standard sont listées dans `package.json` et leurs versions exactes dans `package-lock.json`.

Reconnaissance : [TensorFlow.js COCO-SSD](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd), modèle `ssdlite_mobilenet_v2`. Le code TensorFlow.js et COCO-SSD est sous licence Apache-2.0. Les poids sont téléchargés depuis l’hébergement public TensorFlow à la construction, ils ne sont pas ajoutés au dépôt.

Icônes : Lucide, licence ISC. Polices DM Sans et Space Grotesk, Google Fonts, SIL Open Font License ; des polices système servent de secours si leur chargement échoue.
